# Сопроводительное письмо

Здравствуйте!

Сверстал главную страницу «Парков Москвы» по макету Figma. Проект собирается Vite, разметка — Handlebars-партиалы, стили — SCSS по БЭМ, интерактив — ванильные ES-модули и Swiper 11. Внешних библиотек сверх Swiper нет, ни одного «неопознанного» скрипта на странице не подключено.

**Запуск:** `npm ci` → `npm run dev` (или `npm run build` → `dist/`).

## Что закрыто по ТЗ

**1. Шапка, меню и хлебные крошки физически разделены.** Шапка — партиал `header`, крошки — отдельный партиал `breadcrumbs`, подвал — `footer`. Все три лежат в `index.html` вне `<main>` и вне контейнера с динамическим контентом: крошки стоят между шапкой и `<main>`, подвал — после `</main>`. На главной крошкам нечего показывать, поэтому партиал вызывается без данных и ничего не рисует; на внутренней странице он получает список и выводит `<nav aria-label="Хлебные крошки">` с `aria-current="page"` у последнего пункта. Ничего не «переезжает» вместе с контентом.

**2. Шапка не уезжает.** `position: sticky` стоит на самом блоке `.header`, а не на его контейнере — состояние живёт на блоке, контейнер остаётся контейнером.

**3. Никаких «неопознанных» селектов.** Выпадающий список «Все парки Москвы» — обычная `<button data-map-reset>` со стрелкой-псевдоэлементом, нативных `<select>` и сторонних селект-плагинов (select2 и подобных) на странице нет вообще. Если понадобится настоящий дропдаун с поиском — по ТЗ это отдельное согласование.

**4. Плагины отдают события.** Каждый интерактивный блок инициализируется своим модулем в `src/js/`, обёрнут в `try/catch`: падение одного блока не ломает остальные и пишет причину в консоль. Наружу отдаются события — `hero` (смена слайда), `journals`, `partners:scrolled` (индекс и всего слайдов), `subscribe:subscribed` (после успешной валидации).

**5. Только десктоп.** Макет 1920, контент 1680 (по 120 px сбоку). Мобильная и планшетная вёрстка в тестовом не делались — по условию задания.

**6. Подвал прижат к низу.** `html { height: 100% }`, `body` — flex-колонка с `min-height: 100%`, `main { flex: 1 1 auto }`: на короткой странице подвал упирается в низ окна, на длинной — идёт за контентом.

## Решения, которые стоит знать

- **БЭМ.** Блоки — самостоятельные объекты (карточка подвала, меню, панель фильтров, область карты, колонка «Парки Москвы», панель соцсетей, карточка подписки, строка логотипов). Элементы — только их части. Обёртки-«элементы, которые на самом деле родители» вынесены в отдельные блоки: `footer-card`, `footer-menu`, `footer-emails`, `footer-contacts`, `footer-logos`, `footer-legal`, `map-panel`, `map-filters`, `map-chips`, `map-view`, `map-canvas`, `about-text`, `social-panel`, `subscribe`, `social-link`, `header-media`, `header-search`, `hero-slider`, `hero-slide`, `hero-controls`, `journals-*`, `partners-*`, `news-head`, `interesting-list`. Раскладку держат контейнеры секций — лишних обёрток в разметке нет.
- **Числа из макета** перенесены как есть, включая нестандартные: панель фильтров 634 px и карта 1088 px (блок шире остальных — 1722 px, поэтому у своего контейнера правый отступ 78 px), заезды карточки подписки на −60 px, повороты карточек «В центре внимания» (−8° и 4°).
- **Слайдеры** — Swiper 11. Hero: `rewind` (слайдов два, для `loop` нужно три), автоплей 7 с, полоска прогресса и счётчик «01 — 02». «Увлечения» и «Журнал»: `slidesPerView: 2`, без «доезда» после последнего слайда. «Партнёры»: бесконечная прокрутка по кругу и перетаскивание мышью, клик после перетаскивания подавляется.
- **Валидация подписки** своя, без библиотек: проверка формата, сообщение об ошибке под полем, красная линия только снизу, успешное состояние.
- **Доступность.** Ссылка «Перейти к содержанию» первой в табуляции, `:focus-visible` с собственным кольцом, при `prefers-reduced-motion` автоплей hero выключается.
- **Вес.** Все фотографии переведены из PNG в WebP без изменения размеров: 42,1 МБ → 5,5 МБ, `hero-poster` 4,7 МБ → 305 КБ. Логотипы оставлены PNG (они по 1–13 КБ). Обложка `og-image.jpg` 1200 × 630 лежит в `public/`.

## Ограничения тестового

- Данные моковые: события, новости и партнёры — статичные карточки в партиалах, бэкенда нет.
- Даты в карточке события в макете набраны Inter 16/20.8, у нас PT Root UI 16/21: второй шрифт ради шести строк дат не тянул, разница в 0,2 px строки не видна, а вес и единообразие важнее. Если Inter нужен принципиально — подключается одним `@font-face`.
- Шрифт PT Root UI взят с открытого зеркала (CDN) — для тестового допустимо; в продакшене заменить файлами от дизайнера, имена файлов те же, SCSS менять не придётся.
- Скриншоты и «проход глазами» в 1440/1920 не прикладываю: в этой среде headless-браузер не запускается. Все размеры сверены с макетом по числам, сборка проверена.

Файлы для проверки: `index.html` (точка входа), `src/components/` (партиалы по блокам), `src/styles/`, `src/js/`, `README.md` (стек и решения), `NOTES.md` (что осталось за рамками тестового).
