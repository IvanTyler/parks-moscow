# Парки Москвы — тестовое задание

Вёрстка лендинга «Парки Москвы» по макету Figma. Десктопная версия.

## Стек

| Что | Зачем |
|---|---|
| HTML | разметка страницы, блоки вынесены в отдельные части (partials) |
| SCSS | стили, отдельный файл на каждый блок |
| JavaScript | интерактив: слайдеры, выпадающие списки |
| Vite | сборка и dev-сервер |

## Запуск

```bash
npm install
npm run dev
```

Сборка для продакшена:

```bash
npm run build
```
