# Парки Москвы — тестовое задание

Вёрстка главной страницы «Парки Москвы» по макету Figma (1920). Только десктоп — так в ТЗ.
Без jQuery и CSS-фреймворков: разметка, SCSS и ES-модули. 56 компонентов, один блок — одна папка.

## Стек

| Технология | Зачем |
|---|---|
| [Vite 5](https://vitejs.dev/) | сборка, dev-сервер, хеширование ассетов |
| [vite-plugin-handlebars](https://github.com/alexlafroscia/vite-plugin-handlebars) | партиалы: блок = отдельный HTML-файл |
| SCSS (`sass`) | стили, файл на блок, переменные из макета |
| [Swiper 11](https://swiperjs.com/) | слайдеры: hero, увлечения, журнал, партнёры |
| ES-модули | остальной интерактив, без плагинов-селекторов |
| PT Root UI | шрифт из макета, локальные `woff` в `src/assets/fonts` |

Больше зависимостей нет: `dependencies` — только `swiper`.

## Как запустить

```bash
npm install      # или npm ci
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # посмотреть собранное
```

Node 18+. Сборка кладёт в `dist/` один CSS (~58 КБ) и один JS (~100 КБ), картинки — с хешами.

## Структура

```
index.html                    страница: шапка → крошки → <main> → подвал
public/og-image.jpg           обложка 1200 × 630 для превью в соцсетях
src/
  components/<блок>/
    <блок>.html               разметка блока
    _<блок>.scss              его стили
  js/
    main.js                   точка входа, инициализация модулей
    hero.js                   hero-слайдер: автоплей, стрелки, счётчик, прогресс
    hobbies.js                слайдер «Увлечения»
    journals.js               слайдер журнала + события
    map.js                    фильтры карты: районы, интересы, сброс
    partners.js               бесконечная лента партнёров с перетаскиванием
    subscribe.js              валидация подписки
  styles/
    main.scss                 единственное место, где подключаются блоки (@use)
    _variables.scss           цвета, шрифт, отступы из макета
    _fonts.scss  _reset.scss  _base.scss
  assets/                     images, icons, fonts
COVER-LETTER.md               сопроводительное письмо с решениями по ТЗ
NOTES.md                      что осталось за рамками тестового
```

### Соглашения

- Блок = папка с `<блок>.html` и `_<блок>.scss`. Подключение разметки — `{{> блок}}`,
  стилей — `@use '../components/блок/блок';` в `src/styles/main.scss`.
- Вложенные блоки разрешены: `footer` → `footer-card` → `footer-menu`.
- Handlebars-комментарии только `{{!-- --}}`, обычные `<!-- -->` ломают партиалы.
- Контейнер: `.container` — `max-width: 1920px; padding: 0 120px` → контент 1680, как в макете.
  У карты свой `.container-map` с правым отступом 78 px: панель фильтров 634 + карта 1088 = 1722.
- Раскладку секций держат контейнеры (`.container-map`, `.container-about`), а не обёртки-элементы.

### Имена классов

Родитель — блок, имя плоское через дефис; его потомки — элементы этого блока через `__`:

```scss
.footer-menu { display: flex; gap: 40px; }

.footer-menu-list {
    flex: 0 0 351px;

    &__item { display: block; }     // .footer-menu-list__item
    &__link { color: #fff; }        // .footer-menu-list__link
}
```

Так же живут `map-filters`, `map-canvas`, `footer-legal`, `journals-controls`,
`subscribe-field`, `partners-viewport`, `news-head`. Модификаторы — через `--`
(`hobby-card--kids`, `button--filled`, `partners-viewport--dragging`),
состояния — `is-` (`is-active`, `is-hidden`).
Всего в разметке 204 класса: 92 блока и 112 элементов.

## Решения по ТЗ

- **Шапка, меню и крошки физически разделены.** Шапка — `{{> header}}`, крошки — `{{> breadcrumbs}}`,
  подвал — `{{> footer}}`. Все три в `index.html` вне `<main>` и вне контейнера динамического контента:
  крошки стоят между шапкой и `<main>`, подвал — после `</main>`. На главной крошкам нечего показывать,
  поэтому партиал вызывается без данных и ничего не рисует; на внутренней странице получает
  `crumbs = [{ text, href }, …]` и выводит `nav` с `aria-current="page"` у последнего пункта.
- **Sticky — на самом блоке.** `position: sticky; top: 0; z-index: 20` у `.header`,
  а не у его контейнера: состояние живёт на блоке.
- **Сторонних скриптов для селектов нет.** `select2` не понадобился: «Все парки Москвы» в макете —
  кнопка сброса фильтров (`data-map-reset`), нативных `<select>` на странице нет.
- **Плагины отдают события**, логика не спрятана. Каждый модуль в `try/catch`: падение одного
  блока не ломает остальные и пишет причину в консоль. Слушать можно на `document`:

| Событие | Модуль | `detail` |
|---|---|---|
| `journals:ready` | `src/js/journals.js` | — |
| `journals:slide-change` | `src/js/journals.js` | `{ index }` |
| `partners:scrolled` | `src/js/partners.js` | `{ index, total }` |
| `subscribe:subscribed` | `src/js/subscribe.js` | `{ email }` |

- **Валидация e-mail своя**, без библиотек: «Укажите e-mail» и «Похоже, в адресе опечатка»,
  `aria-invalid`, ошибка не сдвигает кнопку, успех снимает состояние.
- **Подвал прижат к низу:** `html { height: 100% }`, `body` — flex-колонка с `min-height: 100%`,
  `main { flex: 1 1 auto }`. На короткой странице подвал упирается в низ окна.
- **Только десктоп.** Мобильная и планшетная вёрстка в задании не требуются.

## Доступность

- Ссылка «Перейти к содержанию» — первая в табуляции, видна только при фокусе, ведёт на `<main id="main">`.
- `:focus-visible` с собственным кольцом: дефолтное теряется на фотографиях и зелёных панелях.
- При `prefers-reduced-motion: reduce` автоплей hero не включается (`autoplay: false` в `hero.js`),
  переходы и анимации сведены к нулю.
- У полей есть `<label>` (визуально скрытый), у кнопок и навигации — `aria-label`.

## Картинки и мета

- Фотографии — WebP без изменения размеров: 42,1 МБ PNG → **5,5 МБ**. Самый тяжёлый кадр
  `hero-poster` был 4,8 МБ, стал ~300 КБ.
- Логотипы оставлены PNG (по 1–13 КБ): мелкий текст в WebP мылится.
- Иконки, маски и паттерны — SVG.
- `og:image` 1200 × 630 — `public/og-image.jpg` (226 КБ), мета в `<head>`: `og:*`, `og:image:*`,
  `twitter:card`. Путь относительный — при деплое заменить на абсолютный URL домена.

## Что проверено

- `npm run build` проходит без ошибок и предупреждений SCSS.
- Сверка «классы в разметке ↔ селекторы в CSS»: 204 против 226, без стилей остались только
  классы-хуки (`*-controls__next/prev`, `calendar__item`, `hero`, `nav` и подобные) — их вид
  задают `button--next` или родитель.
- Ссылки на ассеты: 77, все живые (21 WebP, 7 PNG, 46 SVG, 3 WOFF), битых нет.
- Итоговый `dist` — 6,5 МБ.

## Ограничения

- Данные моковые: события, новости, журнал и партнёры — статичные карточки в партиалах, бэкенда нет.
- Проход глазами в браузере на 1440 и 1920 не приложен: headless-браузер в этой среде не запускается.
  Все размеры сверены с макетом по числам.
- Даты в карточке события в макете набраны Inter 16/20.8, здесь PT Root UI 16/21: второй шрифт
  ради шести строк дат не подключал, разница 0,2 px строки не видна. При необходимости Inter
  добавляется одним `@font-face`.
- Шрифт PT Root UI взят с открытого зеркала (CDN). Для тестового допустимо, в продакшене
  заменить файлами от дизайнера — имена те же, SCSS менять не придётся.
