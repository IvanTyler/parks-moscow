# Парки Москвы — тестовое задание

Вёрстка главной страницы «Парки Москвы» по макету Figma. Десктоп (ТЗ), 1920 по макету.
Без jQuery, без CSS-фреймворков: только разметка, SCSS и ES-модули.

## Стек

| Что | Зачем |
|---|---|
| [Vite 5](https://vitejs.dev/) | сборка, dev-сервер, хеширование ассетов |
| [vite-plugin-handlebars](https://github.com/alexlafroscia/vite-plugin-handlebars) | партиалы: один блок — один HTML-файл |
| SCSS | стили, отдельный файл на блок, переменные из макета |
| [Swiper 11](https://swiperjs.com/) | слайдеры hero, хобби, журналы |
| Чистые ES-модули | остальной интерактив, без плагинов-селекторов |
| PT Root UI | шрифт из макета, локальные `woff` в `src/assets/fonts` |

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
```

## Структура

```
index.html                  страница: шапка → крошки → main → подвал
src/
  components/<блок>/        блок.html + _блок.scss
  js/                       main.js + модуль на блок
  styles/                   переменные, сброс, база, шрифты, main.scss
  assets/                   images, icons, fonts
NOTES.md                    что готово и что осталось
```

Соглашения: блок = папка с `блок.html` и `_блок.scss`, подключение через `{{> блок}}`,
стили — через `@use` в `src/styles/main.scss`. Классы по BEM, вложенность элементов — не глубже одного уровня.
Контейнер: `.container` — `max-width: 1920px; padding: 0 120px` → контент 1680, как в макете.

## Решения по ТЗ

- **Крошки, меню и подвал физически разведены** с контейнером динамического контента:
  `{{> breadcrumbs}}` и `{{> footer}}` стоят в `index.html` вне `<main>`, см. комментарии там же.
- **Сторонних скриптов для селектов нет.** `select2` не понадобился: «Все парки Москвы» в макете —
  кнопка сброса фильтров (`data-map-reset`), нативных `<select>` на странице нет вообще.
- **Плагины отдают события**, а не прячут логику внутри. Все всплывают, слушать можно на `document`:

| событие | где | `detail` |
|---|---|---|
| `journals:ready` | `src/js/journals.js` | — |
| `journals:slide-change` | `src/js/journals.js` | `{ index }` |
| `partners:scrolled` | `src/js/partners.js` | `{ index, total }` |
| `subscribe:subscribed` | `src/js/subscribe.js` | `{ email }` |

- **Валидация e-mail своя**, на регулярке, без плагинов: сообщения «Укажите e-mail» и
  «Похоже, в адресе опечатка», ошибка не сдвигает кнопку.
- **Подвал прижат к низу** страницы: `body` — flex-колонка, `main { flex: 1 1 auto }`.

## Ограничения

- Только десктоп: брейкпоинт `1024px` есть, но мобильная версия по макету не выверена (в ТЗ не требуется).
- Картинки пока в PNG, ~43 МБ в сборке — пережать в WebP, см. `NOTES.md`.
