# Парки Москвы

Главная страница «Парков Москвы» по макету Figma (1920). Десктоп — так в ТЗ.

## Технологии

- Vite 5 — сборка и dev-сервер
- Handlebars-партиалы — один блок = один HTML-файл
- SCSS — стили, файл на блок
- Swiper 11 — слайдеры
- ES-модули — интерактив без jQuery
- PT Root UI — шрифт из макета

## Как запустить

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка и предпросмотр:

```bash
npm run build    # в dist/
npm run preview
```

## Что сделано

Вся главная по макету: шапка с поиском и меню, hero-слайдер, «В центре внимания», «Увлечения»,
афиша с календарём, карта с фильтрами по районам и интересам, новости, журнал, блок о проекте,
партнёры, подвал. Вёрстка по БЭМ: блок — папка с разметкой и стилями.

## Что добавил от себя

- Sticky-шапку — прилипает при скролле.
- Хлебные крошки отдельным партиалом вне контента: на главной ничего не выводят, на внутреннюю
  страницу передаётся список разделов (`crumbs`), из него собираются ссылки и текущая страница
  с `aria-current="page"`.
- Подвал прижат к низу окна на коротких страницах.
- Доступность: ссылка «к содержанию», видимый фокус, отключение автоплея при
  `prefers-reduced-motion`.
- Сжатие картинок: PNG → WebP, 42 МБ → 5,5 МБ, плюс обложка `og:image` 1200 × 630.
